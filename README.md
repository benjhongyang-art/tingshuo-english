# 聽說

給繁體中文使用者的英文聽力與發音練習。介面是繁體中文，練習內容是日常英文短句。不需要帳號，也不需要後端。

線上版：[https://benjhongyang-art.github.io/tingshuo-english/](https://benjhongyang-art.github.io/tingshuo-english/)。推送到 `main` 後，GitHub Actions 會建置並發佈到 GitHub Pages（倉庫設定的 Pages 來源需為 **GitHub Actions**）。

## 可以做什麼

- **聽力**：用瀏覽器朗讀英文，速度可切「慢速 / 正常」。可以用選擇題作答，或自己聽寫。答完會顯示正確句子、音標和中文意思。
- **發音**：看句子、聽示範，再按麥克風用英文說一次。語音辨識（en-US）會和目標句子比對，給出相似度，並把不一樣的字標出來。
- **十個主題**：日常問候、食物與點餐、旅行移動、工作溝通、購物、健康與看醫生、學校與學習、興趣與休閒、天氣與季節、電話與網路。每個主題 15 句，聽力、發音和閃卡都用得到。
- **單字閃卡**：每個主題附一組單字（英文、中文、音標、例句）。翻面自評「忘記 / 模糊 / 記得」，用 SM-2 間隔排程。首頁會顯示今天待複習的張數。
- **錯題本**：聽力答錯、發音低於 60 分、閃卡按「忘記」、文法答錯，或閱讀理解答錯，會自動收進來。和 AI 對話時，也可以把改正的句子加進來。可以依來源或主題瀏覽，再用聽力或發音重練。連續答對 3 次（發音需 80 分以上）會移出，也可以手動移出。
- **英文對話**：和 AI 用英文聊天。情境有點餐、旅行、工作閒聊、初次見面和自由聊天，程度可切初級、中級、進階。可以打字，也可以用麥克風；回覆會朗讀，並可顯示中文提示。這是靜態網站，請在設定裡貼上自己的 API 金鑰（支援 OpenAI，也可用相容網址和模型）。金鑰只存在這台瀏覽器，費用記入你自己的帳戶。
- **文法練習**：時態、冠詞、介系詞、比較級、疑問句。題目在裝置上，選擇或填空，答完看中文說明。答錯會進錯題本，正確率跟其他進度一起留在這台瀏覽器。
- **閱讀**：初級、中級、進階短文。點句子朗讀，點單字看中文，每篇 3 到 5 題理解測驗，附中文說明。答錯會進錯題本。
- **每日目標**：可設題數或分鐘，首頁看今天的進度。也可以在選定時間用瀏覽器通知提醒。App 開著時會提醒；完全關掉後，只有部分已安裝的瀏覽器能在背景提醒，而且不一定準時。拒絕通知權限時，首頁進度仍然看得到。
- **學習統計**：近 7 天和 30 天的練習量、聽力、發音、文法、閱讀正確率、閃卡張數和錯題本大小。每日紀錄從開始使用這項功能之後才有。
- **深色模式**：可選系統、淺色或深色，選擇會留在這台瀏覽器。
- **安裝到主畫面**：可以當成 PWA 安裝。第一次開啟並完成載入後，聽力、發音、單字、文法、閱讀和錯題本可離線使用。英文對話需要網路，離線時會說明。有新版本時會提示更新。
- **進度**：已練習題數、聽力正確率、發音最高分平均、文法正確率、連續天數，都存在這台裝置的瀏覽器（`localStorage`）。舊的練習紀錄會原樣保留。

## 環境

- Node.js 20 以上
- 聽力播放：支援 Web Speech API `speechSynthesis` 的瀏覽器
- 發音評分：請用 **Chrome** 或 **Edge**（電腦或手機皆可），並允許麥克風。Firefox、部分 iOS 瀏覽器沒有語音辨識，App 會顯示中文說明，仍可聽示範發音。

## 開發

```bash
npm install
npm run dev
```

開發伺服器是 [http://127.0.0.1:43127/tingshuo-english/](http://127.0.0.1:43127/tingshuo-english/)。本機與正式環境都掛在 `/tingshuo-english/` 底下，和 GitHub Pages 的網址一致。

## 測試與建置

```bash
npm test
npm run build
npm run preview
```

## 進度存在哪裡

練習進度的鍵名是 `tingshuo.progress.v1`。單字排程是 `tingshuo.vocab.v1`，錯題本是 `tingshuo.mistakes.v1`，文法成績是 `tingshuo.grammar.v1`。英文對話的 API 金鑰在 `tingshuo.ai.v1`，只存在這台瀏覽器，不會進到專案裡。每日目標是 `tingshuo.goals.v1`，每日練習紀錄是 `tingshuo.activity.v1`，閱讀成績是 `tingshuo.reading.v1`，外觀是 `tingshuo.theme.v1`。這些新紀錄分開存放，不會改寫原本的進度、單字、錯題、文法或 API 金鑰。想重頭開始，在瀏覽器清除這個網站的資料即可。
